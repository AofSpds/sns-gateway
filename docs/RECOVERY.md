# 복구 안내

## 로컬 모듈 없음

Expo Go가 아니라 로컬 native 모듈을 포함한 development/native 빌드가 필요합니다. JS 번들 성공만으로 모듈 설치를 가정하지 않습니다. 파일·개인 키를 보내지 말고 빌드 대상과 안전한 오류 코드만 확인합니다.

## 공유 후 결과가 안 보임

SNS에서 실제로 게시됐을 수도 있습니다. 자동으로 다시 공유하지 말고 해당 SNS를 확인합니다. 앱이 중단된 REQUESTED 기록은 다음 DB 초기화에서 HANDOFF_UNCONFIRMED / RECOVERED_UNKNOWN으로 복구합니다. 화면으로 돌아온 사실을 게시 성공으로 기록하지 않습니다.

## 공유 이미지가 없어짐

합성 JPEG는 cache에 있어 OS가 정리할 수 있습니다. 시험 사진을 다시 생성합니다. 실사용 사진의 보존 관리 기능은 아직 없으며 이 앱 후보에 개인 자료를 맡기지 마세요.

## DB 오류

현재 후보는 스키마 버전 1만 엽니다. 알 수 없는 버전을 자동 삭제하거나 마이그레이션하지 않습니다. 전체 데이터 초기화는 이력 손실이므로 자동 수행하지 않습니다.

## 9시 알림이 안 옴

이 후보는 알림을 아직 등록하지 않습니다. 계산된 다음 9시 표시와 OS 예약을 구분합니다. 이는 설정을 잘못한 것이 아니라 아직 구현되지 않은 범위입니다.
